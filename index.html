⚙️ Настройка один раз

Чтобы расписание было общим для всех, кто открывает этот файл, нужно один раз подключить бесплатную базу данных Firebase (Google). Это займёт 5 минут, карта не нужна.

  1. Откройте console.firebase.google.com и создайте проект (любое имя).
  2. В меню слева выберите Build → Firestore Database → «Создать базу данных» → режим test mode (тестовый режим).
  3. В настройках проекта (⚙️ → Project settings) внизу нажмите «Add app» → веб (значок </>), дайте любое имя.
  4. Скопируйте появившийся объект firebaseConfig (apiKey, projectId и т.д.) и вставьте его сюда:

Настройка сохранится прямо в этом HTML-файле у вас на компьютере. Дальше просто отправьте готовый файл всем, кто должен видеть и редактировать расписание — им ничего настраивать не нужно.
